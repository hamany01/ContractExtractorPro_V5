# JPF Contract Analyzer (v5)

منصة ذكية لتحليل العقود باستخدام الذكاء الاصطناعي، تدعم:

- تسجيل دخول المستخدمين.
- رفع ملفات العقود (Excel, PDF).
- تحليل محتوى العقود وإعطاء ملاحظات ذكية.
- إدارة المستخدمين والملفات.
- دعم التحديث التلقائي عبر GitHub و Render.

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
